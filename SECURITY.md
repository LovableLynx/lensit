# Security

## Download safely

Only download Lens It from the official sources:

- Website: https://wandercoil.github.io/lensit/
- Code: https://github.com/Wandercoil/lensit

Lens It checks the integrity of its packages and AI models during setup and refuses anything that doesn't match. If setup reports a failed check, don't continue. Delete the folder and download it again from the links above.

## Reporting a problem

Please report security issues privately through GitHub's **Report a vulnerability** button on the Security tab. Don't open a public issue.
