How it works: YuNet finds faces and SFace turns each one into 128 numbers. Faces are compared by cosine similarity (a match is ≥ 0.363, OpenCV's recommended threshold). Both models are Apache-2.0, from opencv_zoo, and run with ONNX Runtime Web. Results can include misses, especially for side profiles, sunglasses or dark photos. Source code.
